# Design Execution Package: Prabhuji Books & Scriptures v1.0

This package contains the machine-readable design handoff for the Prabhuji Books & Scriptures module.

## Files

- `prd.md` - Human-readable product and UX requirements.
- `screen-spec.yaml` - Machine-readable screen, behavior, access, analytics, CMS, and QA spec.
- `open-questions.yaml` - Remaining engineering/content questions plus resolved decisions.
- `figma-links.md` - Source Figma links and detected frame/node references.

## Export Path

Recommended Google Drive/wiki path:

```text
Prabhuji / Books & Scriptures / Module Spec / v1.0
```

## MVP Rule

Discovery is free. Reading is Pro.

Free users can browse the Books module, but tapping any book/content item opens the unified paywall directly.

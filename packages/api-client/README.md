# @repo/api-client

Typed HTTP client for `apps/api`, generated from the committed OpenAPI contract (`apps/api/openapi.json`).

`src/types.ts` is generated by `openapi-typescript` from `apps/api/openapi.json` and committed — do not hand-edit it.
`createApiClient(baseUrl)` wraps [`openapi-fetch`](https://openapi-ts.dev/openapi-fetch/) with those types, giving compile-time checked requests/responses.

Regenerate after any route/schema change: `pnpm nx run api-client:generate` (depends on `api:openapi`, which runs `pnpm openapi:emit`). Commit the resulting diff alongside the route change.

No secrets live in this package.
